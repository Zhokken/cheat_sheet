## 🚀 Kom i gang

Følg disse stegene for å kjøre prosjektet lokalt på din maskin.

### Forutsetninger
Du må ha følgende programvare installert:
* Node.js (versjon 18 eller nyere)
* npm eller yarn

### Installasjon

1. **Klone repositoriet:**
   ```bash
   git clone https://github.com
   ```

2. **Gå inn i prosjektmappen:**
   ```bash
   cd repo-navn
   ```

3. **Installer avhengigheter:**
   ```bash
   npm install
   ```

4. **Konfigurer miljøvariabler:**
   Opprett en `.env`-fil i rotmappen og legg til nødvendige nøkler:
   ```env
   PORT=3000
   DATABASE_URL=din_database_url
   ```

5. **Start utviklingsserveren:**
   ```bash
   npm run dev
   ```

## 🤝 Bidra

Bidrag gjør open source-miljøet til et fantastisk sted å lære, inspirere og skape. Alle bidrag settes stor pris på!

1. Fork prosjektet
2. Opprett en branch for din funksjon (`git checkout -b funksjon/NyFunksjon`)
3. Gjør endringene dine (`git commit -m 'Legg til en kul funksjon'`)
4. Push til branchen (`git push origin funksjon/NyFunksjon`)
5. Åpne en **Pull Request**
